Hello friends! Using ChatGPT I made a MOD for the game Dredge. My AI gave himself a name that day, and it is Forge. 

This MOD adds an extra MENU option called Port Services. This new menu brings all options in a PORT into its MENU and when navigating, the animations have been sped up. When you exit a "vendor" you return to my menu.

There is a button to return to vanilla menu at any point.
